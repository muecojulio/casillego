# Casillego

Alarma de llegada para metro, Cablebús, tren y transporte público. Eliges dónde subes, dónde cambias y dónde bajas. Al elegir una estación puedes marcar la salida: norte, sur, oriente o poniente. Si el mapa trae la puerta, el aviso usa esa. Puedes dejar una nota, guardar casa y trabajo, y la ruta sirve de regreso. En el viaje ves metros, minutos a pie y de qué lado queda la parada. Si te pasas, avisa. Al bajar, puedes guardar esa distancia como aviso.

Después de abrirla una vez con internet, la alarma y las rutas guardadas funcionan sin conexión. Buscar una parada nueva y ver calles nuevas sigue necesitando red.

Datos en vivo, sin llave: Nominatim y Overpass (OpenStreetMap) para buscar, [OpenFreeMap](https://openfreemap.org) para el mapa.

App instalable (PWA). Node.js 24.x.
